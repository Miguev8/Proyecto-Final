Proyecto Final - Plataforma de Retos Personales

Materia: Desarrollo Web Avanzado

Framework: Laravel 12 con Breeze (Blade)

Base de datos objetivo: MySQL

1. Objetivo

Construir una plataforma para crear retos personales, registrar participantes y actividades, con autenticacion, roles, CRUD completo y API REST.

2. Tecnologias usadas

  • PHP 8.x
  • Laravel 12
  • Laravel Breeze + Blade + Tailwind
  • Eloquent ORM
  • MySQL (configurado en entorno)
  • SQLite (usado temporalmente durante montaje inicial)

3. Desarrollo paso por paso

Paso 1 - Instalacion del proyecto

composer create-project laravel/laravel retos-personales

Paso 2 - Configuracion de base de datos

Se dejo la configuracion activa para MySQL.

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=retos_personales
DB_USERNAME=root
DB_PASSWORD=

Paso 3 - Instalacion de autenticacion

composer require laravel/breeze --dev
php artisan breeze:install blade
npm install
npm run build

Paso 4 - Migraciones y modelo relacional

  • users (con role: admin|usuario)
  • retos (FK a users)
  • participantes (FK a users y retos)
  • actividades (FK a participantes)

Paso 5 - Modelos y relaciones

Modelos creados: User, Reto, Participante, Actividad. En Actividad se fijo el nombre de tabla para evitar pluralizacion incorrecta.

protected $table = 'actividades';

Paso 6 - CRUD web

Controladores con validaciones:

  • RetoController
  • ParticipanteController
  • ActividadController

Paso 7 - Roles y middleware

Middleware personalizado EnsureRole con alias role.

  • Rutas de retos: autenticado
  • Rutas de participantes y actividades: solo admin

Paso 8 - API REST

MetodoEndpointDescripcion
GET/api/retosListar retos
POST/api/retosCrear reto
GET/api/retos/{id}Obtener detalle
PUT/PATCH/api/retos/{id}Actualizar
DELETE/api/retos/{id}Eliminar

Paso 9 - Seeders de prueba

Se cargaron usuarios, retos, participantes y actividades de demostracion.

php artisan migrate:fresh --seed

4. Diagrama de base de datos

  1. Login y registro funcionando
  2. CRUD completo de retos
  3. Control de acceso por rol (403 para usuario normal en rutas admin)
  4. CRUD de participantes y actividades con cuenta admin
  5. Pruebas API en Postman

7. Estado final

El proyecto cumple requisitos de framework, modelo relacional, autenticacion, roles, CRUD, API REST y seeders. La configuracion de entorno quedo preparada para MySQL.

8. Comandos de ejecucion

php artisan migrate:fresh --seed
php artisan serve
npm run dev
