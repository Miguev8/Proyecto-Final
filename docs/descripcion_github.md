# Descripción para GitHub

Plataforma de Retos Personales es una aplicación web desarrollada con Laravel 12 para gestionar retos, participantes y actividades con autenticación, control de roles, CRUD completo y una API REST para retos. Incluye documentación técnica, base de datos relacional, seeders y una interfaz Blade con Breeze.

## Texto corto para el repositorio

Aplicación web en Laravel 12 para administrar retos personales con roles de usuario y administrador, CRUD de retos, participantes y actividades, API REST y documentación completa del proyecto.
